### About me

I'm a Graduate Trainee in Software and Data Science at **Nkana Water Supply and Sanitation Company**, with a BEng in Computer Engineering (with Credit) from the **Copperbelt University**.

My job is to find the processes that still run on Excel, email and paper, and replace them with systems that billing, customer service, HR and audit teams use every day. I design them, build them and keep them running inside a working water utility.

-  Currently building a **GIS operations map** and an **internal audit platform**
-  Working towards automating Zambia's everyday processes, in line with Agenda 2030
-  Have a manual process you'd like automated? [Send me the idea](https://dalitsomalama-dev.vercel.app/ideas)

### Selected work

Most of these run on a private company network, so the code is private. Each links to a case study with redacted screenshots, and some have a live simulation on generated data.

| Project | What it does | Stack |
|---|---|---|
| [**GIS Operations Map**](https://dalitsomalama-dev.vercel.app/systems/gis-operations-map) | Every customer property on a map, coloured by billing, consumption, debt and complaint status | Laravel · PostgreSQL · Leaflet |
| [**Revenue & Billing Dashboard**](https://dalitsomalama-dev.vercel.app/systems/revenue-billing-dashboard) | Real-time billing and collections against targets, per branch and area | Laravel · SQL Server · C# Blazor (v1) |
| [**Automated Meter Discrepancy Reports**](https://dalitsomalama-dev.vercel.app/systems/meter-discrepancy-reports) | Validates monthly meter readings and produces branch-level reports with no Excel work | Laravel · SQL Server |
| [**Audit Management System**](https://dalitsomalama-dev.vercel.app/systems/audit-management-system) | Audit plans, information requests, findings and follow-ups in one place | React · NestJS · PostgreSQL · Redis |
| [**Attendance Management**](https://dalitsomalama-dev.vercel.app/systems/attendance-management-system) | QR-code attendance across a web portal and mobile app | React · NestJS · PostgreSQL |
| [**Water Quality IoT Monitor**](https://dalitsomalama-dev.vercel.app/systems/water-quality-monitor) | ESP32 with pH, turbidity and ammonia probes streaming live readings (CBU group project) | ESP32 · C++ · Wi-Fi |

**Public repositories:** [dalitsomalama.dev](https://github.com/DalitsoMalama/dalitsomalama.dev) (this portfolio, built with Next.js 16 and Supabase) · [HR Analytics in Power BI](https://github.com/DalitsoMalama/HR_Analytics_PowerBi) · [CBU Challenge website](https://github.com/DalitsoMalama/CBU-Challenge)
